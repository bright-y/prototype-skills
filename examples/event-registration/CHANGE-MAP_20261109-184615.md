# 活动报名案例：需求到文件

修订时间：2026-11-09 18:46:15（Asia/Shanghai）。最终维护入口为 `after-change/index.html`。下面路径均相对于 `after-change/`。

| 常见需求 | 首先修改 | 联动检查 |
| --- | --- | --- |
| 改活动名称、时间、地点 | `assets/js/data.js` | 列表、报名摘要与成功页共用数据 |
| 改列表布局、报名页文案、成功提示 | `assets/js/pages.js` | 页面导航、窄屏换行 |
| 增加/改名一个表单字段或校验规则 | `assets/js/fields.js` | 确认和成功详情由同一字段定义生成 |
| 持久化一个新字段 | `assets/js/store.js` | 保留旧记录，补充测试 |
| 改确认/取消、Escape、失败后的重试 | `assets/js/dialog.js` | 取消零写入、失败不显示成功 |
| 改路由、表单草稿、事件委托 | `assets/js/app.js` | 浏览器前进/后退、重复进入、重复点击 |
| 改主题、按钮、表单和响应式布局 | `assets/styles.css` | 桌面、窄屏、可见焦点 |
| 改页面壳或脚本顺序 | `index.html` | 全流程与资源加载 |

## 本次“增加必填手机号”的实际改动

1. `assets/js/fields.js`：增加 `phone` 字段，包括标题、tel 输入、格式限制和错误提示。
2. `assets/js/store.js`：把新报名的 `phone` 写入记录。旧记录原样保留，不要求补填。

`pages.js`、`dialog.js` 和 `app.js` 无需修改：表单、确认弹窗和成功详情复用同一组字段定义。CSS 和入口也保持不变。完整差异见 [手机号改动补丁](phone-field_20261109-175441.patch)。

不要直接编辑 `before/` 来继续业务开发；它是用于回看和验证提取结果的基线。不要加载两套页面或事件实现。
