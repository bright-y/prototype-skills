环境：Codex 内置浏览器；同一个 `127.0.0.1` HTTP 源；默认桌面视口与 390 × 844 窄屏视口。只提供本案例目录，验收后已停止临时服务。`file://` 导航受工具限制，未将其作为实测环境。

| 检查 | 实际观察 |

| 原始版必填与取消 | 空表单显示姓名/邮箱错误；填写演示信息可确认；取消后报名数为 0 |
| 原始版保存与刷新 | 确认后报名数为 1，刷新后成功详情仍显示姓名与邮箱 |
| 拆分版流程 | Escape 取消不新增记录；确认后总数为 2，刷新仍能查看 |

验收中修正了两处三版共用行为：合法提交后清除旧校验提示；页面焦点切换避免将页头滚出视口。修正同步应用于原始输入与两个拆分快照，再次验证提取一致性。维护版相对拆分版仍然只改变字段定义和存储两个文件。

这些检查仅覆盖当前内置浏览器和演示数据。尚未覆盖 Safari、Firefox、独立 Chrome 的兼容性、真正手机设备、完整无障碍审计或 `file://` 存储行为。截图是单次运行证据，不代表所有环境的像素或行为保证。

- 手机号只检查中国大陆 11 位格式；不发送短信，不验证归属或可达性。
- 没有后端、登录、网络提交、并发写入控制或生产级数据服务。
- 没有测量或宣称节省时间、提升百分比等效果。
- 样例用于展示拆分职责、两文件迭代和保留旧记录的思路。
